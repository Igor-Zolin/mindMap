# MindMap Studio

Браузерный редактор ментальных карт. Карты можно создавать и менять на холсте или через MCP. В обоих интерфейсах используются одни и те же данные пользователя.

## Локальный запуск

Нужен Node.js 22 или новее. В PowerShell из каталога mindMap:

    npm ci
    New-Item -ItemType Directory -Force .local | Out-Null
    Copy-Item -LiteralPath '../slides/.local/users.json' -Destination '.local/users.json'
    npm start

Откройте [редактор](http://127.0.0.1:4180/). В гостевом режиме можно создавать и редактировать карты. Они сохраняются в текущем браузере. Для доступа к отдельному серверному пространству и MCP войдите своим ключом от Slides через кнопку «Гость» в боковой панели. Чтобы перенести карту из одного пространства в другое, экспортируйте её в JSON и импортируйте после входа или выхода.

«Импорт» принимает JSON, созданный кнопкой «Экспорт», и сохраняет отдельную копию с новым идентификатором. Кнопка «Просмотр» скрывает инструменты редактирования. В этом режиме щелчок по узлу открывает заметки справа. Ширину панели просмотра и панели редактирования можно менять за левую границу или клавишами со стрелками. Название, заметки и цвет узла сохраняются автоматически. Переключатель темы запоминает выбор браузера.

В меню «Экспорт» есть автономный HTML для просмотра. Откройте скачанный файл в браузере, чтобы перемещаться по карте, менять масштаб и читать заметки узлов без запуска MindMap или подключения к интернету.

В заметках работает Markdown. Кнопка «Предпросмотр Markdown» показывает форматирование в редакторе. У выделенного узла минусы на соединениях сворачивают отдельные дочерние ветви. При масштабе от 50% их диаметр составляет 20–34 экранных пикселя. Точки раскрытия увеличиваются при отдалении карты и скрываются при масштабе ниже 35%. В HTML попадают все узлы, а состояние свёрнутых ветвей определяет начальный вид файла.

Плюс для нового ответвления появляется под видимыми дочерними ветвями выделенного узла. Если они все свёрнуты или у узла пока нет ветвей, плюс располагается сбоку. Плюс под самим узлом создаёт соседний узел с тем же родителем. У центрального узла есть отдельный плюс для каждой стороны. Верхняя кнопка «Добавить узел» при выделенном центре выбирает менее занятую сторону. Введите название в новой ветви на холсте и нажмите Enter или щёлкните вне поля. Esc и выход из пустого поля отменяют создание.

Кнопка «Свободно» включает свободное размещение для текущей карты. Перетаскивание ветви на пустое место меняет её положение вместе со всеми потомками. Карточки раздвигаются с сохранением направления связей и порядка соседних ветвей. Сохранённые координаты используются в текстовом виде. Повторное нажатие возвращает автоматическую раскладку. В режиме просмотра и HTML-экспорте используется выбранная раскладка. JSON переносит обе раскладки.

Чтобы выделить несколько узлов, протяните рамку левой кнопкой мыши по фону или щёлкайте по узлам с зажатым Shift. Shift также добавляет узлы к выделению рамкой. При групповом выделении справа можно свернуть выбранные ветви целиком, скрыть или показать их дочерние ветви, оставив выделенные узлы на холсте, или удалить выбранные ветви. Del тоже открывает подтверждение удаления. При выборе центрального узла там же можно скрыть или показать все ветви карты.

Кнопки слева внизу холста и клавиши Ctrl+Z и Ctrl+Y отменяют и возвращают правки и сворачивание ветвей. История ведётся отдельно для каждой карты в текущей вкладке. После обновления карты из другого клиента начинается новая история.

Удерживайте пробел и двигайте мышь или перетаскивайте холст зажатым колёсиком. Чтобы сменить родителя ветви, перетащите её на другой узел. При переносе на центр сторона определяется половиной центрального узла, на которую вы отпустили ветвь.

Кнопка «Текст» показывает цветные подписи со стрелками. Длинные названия до 320 символов расширяют столбец и переносятся на строки. Название можно изменить на узле двойным щелчком или клавишей F2. Enter или щелчок вне поля сохраняет правку, Esc отменяет её.

В свойствах узла доступны восемь основных цветов. Стрелка рядом открывает ещё четыре оттенка каждого цвета, от светлых к глубоким.

Включите «Тачпад» рядом с масштабом холста, чтобы движение двумя пальцами сдвигало карту, а щипок масштабировал её вокруг курсора. В обычном режиме колесо меняет масштаб. Выбор сохраняется в браузере.

Копировать реестр хешей нужно при первоначальной настройке и после выдачи, замены или отзыва ключей в Slides. Перезапустите mindMap после обновления файла. У приложений отдельные процессы, настройки, адреса и данные. Для запуска mindMap используется только его локальная копия реестра. Реестр содержит SHA-256 хеши ключей.

Настройки:

- `PORT` задаёт порт локального HTTP-сервера. По умолчанию он слушает `127.0.0.1:4180`.
- `MINDMAP_DATA_DIR` задаёт каталог данных. По умолчанию используется `.local`. Запускайте один процесс Node.js на каталог данных.
- `MINDMAP_USERS_JSON` принимает тот же JSON со списками SHA-256 хешей, что и `SLIDES_USERS_JSON`. Приоритет у переменной окружения.
- `MINDMAP_ACCESS_TOKEN` поддерживает старый одиночный ключ владельца, если `MINDMAP_USERS_JSON` не задан.
- Карты лежат в `.local/maps/<идентификатор пользователя в hex>/workspace.json`. Сохранение идёт на сервер, а ключ хранится в памяти вкладки. После перезагрузки страницы войдите снова.

## MCP

Адрес локального сервера — `http://127.0.0.1:4180/mcp`. Транспорт — [Streamable HTTP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports#streamable-http). В заголовке `Authorization` передайте `Bearer ВАШ_КЛЮЧ_SLIDES`.

Пример для клиента, который принимает параметры `url` и `headers`:

```json
{
  "mcpServers": {
    "mindmap": {
      "url": "http://127.0.0.1:4180/mcp",
      "headers": { "Authorization": "Bearer YOUR_SLIDES_KEY" }
    }
  }
}
```

| Инструмент | Действие |
| --- | --- |
| `list_maps` | Список карт и их текущие версии |
| `get_map` | Карта с узлами, цветами и заметками |
| `create_map` | Новая карта с необязательным массивом ветвей |
| `add_node` | Добавить дочерний узел. `side` задаёт сторону ветви центра, `afterId` — соседний узел, после которого вставляется новый |
| `update_node` | Изменить название, заметки или цвет |
| `set_node_colors` | Применить `color` ко всем узлам из `nodeIds` одной операцией |
| `move_node` | Перенести узел с потомками. `side` задаёт сторону при переносе к центру, `position` — координаты центра относительно родителя для свободной раскладки |
| `set_layout` | Переключить `layout` между `auto` и `free`. В `positions` можно задать координаты узлов относительно их родителей |
| `delete_node` | Удалить ветвь с потомками по `nodeId` или несколько ветвей одной операцией по `nodeIds` |
| `delete_map` | Удалить карту |

Например, вызов `create_map` создаст сразу три узла:

```json
{
  "title": "Запуск продукта",
  "branches": [
    { "id": "strategy", "parentId": "root", "title": "Стратегия", "color": "violet" },
    { "id": "audience", "parentId": "strategy", "title": "Аудитория" }
  ]
}
```

Центральный узел имеет ID `root`. Для изменения существующей карты передайте её `mapId` и `expectedRevision` из последнего чтения. Если карта изменилась, заново прочитайте её перед повторной записью. В открытой вкладке изменения через MCP подхватываются примерно за 2,5 секунды.

## Размещение на Cloudflare

Конфигурация создаёт отдельный Worker `mind-map-studio`. Хранилище карт разбито по пользователям с помощью SQLite Durable Objects.

    npm run check:cloudflare
    npx wrangler login
    npm run deploy:cloudflare
    Get-Content -Raw .local/users.json | npx wrangler secret put MINDMAP_USERS_JSON

Wrangler выведет URL редактора. Используйте тот же URL с суффиксом `/mcp` в MCP-клиенте. У облачной установки свой реестр. После изменения ключей обновите её секрет той же командой. До настройки ключей API и MCP возвращают HTTP 503. Файлы локальных карт и облачное хранилище независимы.
